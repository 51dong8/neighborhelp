邻里帮帮 (NeighborHelp) - 社区互助全栈平台邻里帮帮 是一款基于 Spring Boot 3 和 Vue 3 (uni-app) 开发的社区互助平台。它旨在通过数字化的方式连接邻里，提供需求发布、订单匹配、积分奖励及智能社区服务，构建一个有温度的社区共享经济生态。🚀 核心功能互助订单系统：支持用户发布需求（代买、维修、寻物等）并由邻居接单处理，包含完整的订单状态流转逻辑。积分激励体系：通过帮助他人获得积分，积分可用于在积分商城兑换物品，并设有信用评分与用户等级制度。AI 智能助手：接入阿里云百炼（通义千问）模型，为用户提供实时社区咨询与操作引导。多模态交互：集成百度 AI 语音识别与 OCR 识别功能，提升用户在移动端的操作便捷性。地理位置感知：利用高德地图 API 实现逆地理编码，自动获取并验证用户的真实社区位置。实时通知：内置消息通知模块，确保用户第一时间掌握订单状态变更。🛠️ 技术栈领域技术方案后端Spring Boot 3.4.1, Spring Security + JWT持久层MyBatis-Plus, MySQL 8.0缓存/中间件Redis, RestTemplate前端Vue 3, Vite, uni-app (跨平台开发)云服务阿里云 OSS (文件存储), 阿里云百炼 (AI), 百度 AI, 高德 API
